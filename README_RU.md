## ✨ Особенности

- 🦙 **Работа с локальными LLM моделями** — автоматическая установка и управление Ollama;
- 🤔 **Поддержка думающих моделей** — работа с моделями, поддерживающими процесс размышления;
- 💬 **Интерактивный чат** — полнофункциональный чат с сохранением истории сообщений;
- 🔍 **Интеллектуальный анализ документов (RAG)** — задавайте вопросы по документам, получайте ответы на основе их содержимого;
- 📝 **Переводчик текста** — быстрый перевод обычного текста;
- 🕹️ **Работа с PDF-документами** — просмотр, перевод и анализ PDF файлов;
- 📄 **Режимы работы с PDF**:
  - Режим инструкции — задавайте вопросы по документу;
  - Режим переводчика — автоматический перевод содержимого PDF;
- 🤫 **Полная конфиденциальность** — все данные обрабатываются локально, без отправки в интернет;
- 📲 **Удобный интерфейс** — минималистичный дизайн;
- 🎨 **Настраиваемые темы** — выбор цветовой схемы оформления;
- 🚀 **Полностью автономное приложение** — работает без подключения к интернету.

## ⚙️ Первоначальная настройка

### Использование предустановленной внешней Ollama

> **Примечание:** Провайдер внешней Ollama отключен на macOS из-за ограничений Gatekeeper, которые блокируют локальные сетевые запросы. В будущем планируется оплатить подписку Apple для подписи и нотариального заверения кода.

Если у вас уже установлена и запущена внешняя Ollama, выберите провайдер **Ollama** в разделе **API конфигурация** и вручную укажите URL и модель.

### Использование встроенной Ollama

Если при первом запуске приложения была автоматически загружена Ollama, выберите провайдер **Embedded Ollama** в разделе **API конфигурация** и загрузите желаемую модель через кнопку **Управление моделями**.

### Настройка RAG

Для использования RAG (интеллектуального анализа документов) загрузите модель эмбеддингов через **Управление моделями эмбеддингов** в разделе **RAG конфигурация** и настройте параметры RAG по необходимости.

## 🖥️ Desktop Tauri (Rust dual-mode)

Нативный desktop-host на Tauri 2 (рядом с временным Electron и Docker/server): команды сборки/запуска, prerequisites по ОС, канонические артефакты (Linux AppImage, macOS arm64 DMG, Windows portable zip) и матрица verified/unverified — в [docs/DESKTOP_TAURI.md](docs/DESKTOP_TAURI.md). Electron остаётся до атома 6.1 после закрытия Fedora AppImage gate.

## 🔒 Безопасность и конфиденциальность

Underlator разработан для работы с чувствительными данными:

- ✅ **Только локальные LLM** — все обработка происходит на вашем компьютере
- ✅ **Локальное хранение** — все данные хранятся только на вашем устройстве
- ✅ **Без интернета** — приложение работает полностью автономно
- ✅ **Никаких внешних запросов** — ваши документы и сообщения никогда не покидают ваш компьютер

## 🗑️ Удаление

Данные приложения (чаты, RAG векторы и прочие файлы) хранятся в стандартной директории userData Electron:

- **macOS**: `~/Library/Application Support/Underlator/`
- **Linux**: `~/.config/Underlator/`
- **Windows**: `%APPDATA%\Underlator\` (обычно `C:\Users\<username>\AppData\Roaming\Underlator\`)

Для полного удаления приложения удалите эту папку после удаления самого приложения.
