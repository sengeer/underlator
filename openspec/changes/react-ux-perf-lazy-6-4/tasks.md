# Tasks

Атом выполняется пошагово. Apply НЕ имеет права закрыть все три оптимизации одним комком.

Оптимизация N → агент останавливается и пишет «готово к ручному тесту»
→ пользователь тестирует UI и отвечает: подтвердить / опровергнуть (+ симптомы)
→ если опровергнуто: агент чинит ту же оптимизацию N и снова checkpoint
→ если подтверждено: агент переходит к оптимизации N+1

Три группы ниже. Явный STOP после каждой:

1. settings — без ручного confirm не начинать popup
2. popup lazy + общий helper — без ручного confirm не начинать chat
3. chat lazy на том же helper

Чекбокс «пользователь подтвердил N» агент НЕ отмечает сам: его ставит только пользователь. Пока он пуст, следующая группа не начинается. При «опровергнуть» агент правит задачи той же группы и снова выходит на её STOP, не переходя к N+1.
